# Uso de IA

Herramienta utilizada: Claude (Anthropic).

## Para qué se usó
- Entender y ordenar los pasos de la guía de actividad (Git colaborativo y consumo de APIs).
- Resolver errores de Git y npm: repositorio vacío, rutas de carpeta y un conflicto de dependencias entre TypeScript 7 y typescript-eslint.
- Obtener una base del componente `PokemonCard` y un borrador de la descripción del pull request.

## Qué se hizo por cuenta propia
- Creación del repositorio, configuración de Git y subida del proyecto base.
- Ejecución y prueba de la aplicación (`npm run dev`) y revisión con `npm run lint`.

## Qué se verificó
- La aplicación muestra datos reales de la API y maneja carga y error.
