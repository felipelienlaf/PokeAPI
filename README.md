# Buscador de Pokémon

Aplicación web en React + TypeScript que consume la PokéAPI para mostrar información de Pokémon. Proyecto de la asignatura Desarrollo de Front-End.

## Integrantes
- felipelienlaf

## Tecnologías
React, TypeScript, Vite, ESLint, PokéAPI (https://pokeapi.co/)

## Cómo ejecutarlo
1. `git clone https://github.com/felipelienlaf/PokeAPI.git`
2. `cd PokeAPI`
3. `npm install`
4. `npm run dev`
5. Abrir http://localhost:5173/

## Flujo de trabajo
Él integrante trabajó en su propia rama y entregó sus cambios mediante pull request, con revisión cruzada.
